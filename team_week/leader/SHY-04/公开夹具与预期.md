# SHY-04 公开夹具与联测预期

所有人从 [SHY-04 固定提交](README.md) 构建并运行同一套夹具。表名为 `public.week_demo`，数据为公开合成样例。每类故障使用独立的隔离实例或隔离状态；报告写明提交、用例、预期、实测、退出码及证据路径。

## 正常链路

总入口负责创建隔离实例、执行 `fides_setup;`、导入 `sse_sql/SSE_v1.sql` 并初始化客户端状态。下列 SQL 是夹具向已初始化的 gsql 用户入口发送的业务请求。

```sql
CREATE TABLE week_demo (ind text, keyword text SSE='FIDES', payload text)
    WITH (sse_storage='ROW_AEAD_V1');
INSERT INTO week_demo VALUES
    ('1', 'apple', 'red apple'),
    ('2', 'apple', 'green apple'),
    ('3', 'banana', 'yellow banana');
SELECT * FROM week_demo WHERE keyword='apple';
SELECT * FROM week_demo WHERE keyword='banana';
SELECT * FROM week_demo WHERE keyword='apple';
SELECT * FROM week_demo WHERE keyword='review_unknown';
INSERT INTO week_demo VALUES ('4', 'apple', 'new apple');
SELECT * FROM week_demo WHERE keyword='apple';
```

| 检查 | 预期 |
| --- | --- |
| 初始写入 | 主表三条 `(rid, data_blob)`，索引三条 `(ut, locator_blob)`。业务和位置封装分别能通过对应的客户端认证，rid 为 32 位十六进制字符串。 |
| 第一次 `apple` | 完整行多重集合为 `1\|apple\|red apple` 和 `2\|apple\|green apple`，各一条；返回位置、重插位置与回查的 rid 集合一致。 |
| `banana`、重开查询、未知词 | `banana` 返回 `3\|banana\|yellow banana`。重新启动 gsql 进程查询 `apple` 仍为原两条。`review_unknown` 返回零行，业务请求和状态均无变化。 |
| 重插与计数 | 首次检索时 `apple` 的 `add_count` 为 2，两个位置重插后为 4，仍返回两条。重插仅更新索引，业务记录数保持三条。 |
| 追加后重复搜索 | `apple` 的完整行多重集合在原结果中增加一条 `4\|apple\|new apple`。连续三次一致，业务表及索引各四条。 |
| 文本和大小边界 | `('中文编号','中文 苹果 space','前后 空格 中文')`、`('quoted', 'it''s AND OR not', 'o''brien apple')` 和 `('','','')` 精确往返。三列最大 UTF-8 字节数分别为 16,384、1,024、16,384，最大业务封装为 45,144 个 Base64 字符。单字段超出 1 字节、NULL 和未支持语句均非零退出且无副作用。 |

夹具定义及比对规则在 [ZYC 实库用例](../../zhang_yongchang/tools/zyc_cases.py) 和 [LZM 实库用例](../../liu_zhuoming/LZM-03/preflight/live-cases.py)。逐项实测见 [ZYC 结果](evidence/results.json) 和 [LZM 结果](evidence/lzm-live-results.json)。
