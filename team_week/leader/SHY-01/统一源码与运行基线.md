## 复跑方式

在 Windows PowerShell 中执行，prepare.sh 每次创建新的专用副本和环境，结果写入本交付目录。保留当前证据时先复制整份交付目录到新位置再执行。脚本从自身目录定位资源。

```powershell
wsl -d CentOS7 -u root -- bash '/mnt/c/Study/创新训练计划/team_week/leader/SHY-01/prepare.sh'
wsl -d CentOS7 -u root -- bash '/mnt/c/Study/创新训练计划/team_week/leader/SHY-01/audit.sh'
wsl -d CentOS7 -u root -- bash '/mnt/c/Study/创新训练计划/team_week/leader/SHY-01/build-smoke.sh'
wsl -d CentOS7 -u root -- bash '/mnt/c/Study/创新训练计划/team_week/leader/SHY-01/final-check.sh'
python team_week/leader/SHY-01/verify_delivery.py
```

root 仅负责创建隔离目录和挂载。编译、安装、初始化与数据库命令由脚本切换为 omm 执行。构建环境读取 `/home/omm/.sse_opengauss_env`，包含 GCC 7.3.0、Boost 1.72、两份 RELIC 和 SSE 密码库路径。加载证据对应私有挂载内的程序。

后续仅做独立编译时，参考 build-smoke.sh 的挂载与 as_omm 调用，在私有命名空间内执行 make。成员应分别使用独立副本与状态路径，当前保留的 SHY-01 环境用于基线追溯。
